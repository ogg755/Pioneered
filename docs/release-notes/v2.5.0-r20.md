# v2.5.0-r20 — centered banners, 3 s duration, input-transparent overlays

<!-- debs: rebuild -->

Follow-up to r19.1 (which made the force-eject hold survive the USB LOCKED
banner, but left the banners off-center). New Mixxx build + skin.

- **Banners centered again** — the popup overlays return to the full-screen
  centered arrangement from r18. A new `banner-overlay-transparency.patch`
  (patch 9) teaches the skin parser an optional
  `<TransparentForMouseEvents>` node, and the overlays use it: the
  full-screen layer is skipped by mouse hit-testing entirely, so showing a
  banner over the held USB button no longer sends the button the Leave
  event that faked a release and cancelled the hold. The r19.1 workaround
  (shrinking the overlay) is reverted.
- **Banners last 3 s** (was 2 s) — more time to read the longer messages,
  e.g. the force-eject instructions.
- Banners no longer block touches anywhere on screen while visible.

## Install (on the Pi)

```
sudo ./update-pioneered.sh
```

## Field checks

1. Play from USB A, hold USB A: banner appears centered at 5 s, flash
   continues, deck stops and stick ejects at 10 s.
2. Banners (USB LOCKED / PAUSE DECK TO LOAD / EJECT FAILED) show centered
   and stay up 3 s.
3. While a banner is up, the rest of the touchscreen still responds.
