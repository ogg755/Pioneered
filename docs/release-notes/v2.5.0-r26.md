# v2.5.0-r26 — load returns to Overview, tap-off closes the settings menu

<!-- debs: rebuild -->

New Mixxx build plus a skin change. Two workflow fixes, nothing else changes.

- **A successful load takes you back to the Overview tab**
  (`load-returns-to-overview.patch`, patch 17). Browsing, hitting LOAD and
  then having to tap *Overview* to see the track you just loaded is a step a
  CDJ doesn't make you take. `WTrackTableView::loadSelectedTrackToGroup` now
  writes the Overview tab's own control once the load has actually been
  emitted — the same thing tapping the tab does.

  It only fires on a load that really happened. **A deck still playing the
  previous track blocks the load** (the existing "PAUSE DECK TO LOAD" guard),
  and that path returns before the tab switch, so a refused load leaves you in
  the browser with the banner and your place in the list — the view never
  jumps away from something that didn't happen. An empty selection and a row
  with no track behave the same way. Preview decks are excluded: previewing is
  browsing, so it keeps you in the browser.

- **Tapping outside the settings panel closes it** (skin only). The cog menu
  was modal — it swallowed every tap outside the panel and BACK was the only
  way out. The backdrop around the panel is now four transparent buttons that
  make exactly the press BACK makes: close, and clear any armed confirm, so a
  half-armed POWER OFF can never survive being tapped away. BACK is unchanged.

  The panel's own dead space stays inert on purpose — the buttons fence the
  panel in rather than sitting behind it, so missing POWER OFF by a few pixels
  doesn't dismiss the menu out from under you.

## Install (on the Pi)

```
sudo ./update-pioneered.sh
```

## Field checks

1. With **deck 1 paused**, go to Browse, pick a track, tap **LOAD 1**: the
   track loads *and* the screen switches to Overview by itself.
2. With **deck 1 playing**, tap **LOAD 1**: the "PAUSE DECK TO LOAD" banner
   appears, the deck keeps playing the old track, and you stay in Browse with
   the same row still selected — no jump to Overview.
3. Repeat 1 and 2 from the **Search** tab: same behaviour.
4. Load with the **DDJ-400's own LOAD button** — same auto-return (it presses
   the same control).
5. Open the cog menu and tap the dark area above/below/beside the panel: it
   closes. Tap the empty space *inside* the panel (between the buttons): it
   stays open.
6. Tap **POWER OFF** once so it turns red ("TAP AGAIN TO POWER OFF"), then tap
   the backdrop to dismiss. Reopen the menu: POWER OFF must be back to its
   safe face, not still armed.
7. The backdrop is invisible — no button outlines or fills anywhere around the
   panel, before or during a tap.
