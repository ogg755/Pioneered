# v2.5.0-r24 — slimmer CDJ/XDJ-style beatgrid

<!-- debs: rebuild -->

New Mixxx build. Restyles the beatgrid overlay on the waveform to match the
Pioneer CDJ/XDJ look — nothing else changes.

- **Beat marks are now short ticks at the top and bottom** instead of faint
  lines running through the whole waveform (`beatgrid-ticks.patch`, patch 15).
  The middle of the waveform stays clear, so the wave itself is easier to read.
- **Bar starts are thin red bars, not big red arrows.** The downbeat markers
  (every 4th beat, anchored on the rekordbox "1") were large red triangles at
  the top and bottom edges; they are now slim red vertical bars, the same
  height as the beat ticks — the CDJ/XDJ beatgrid style.
- Both waveform renderers (the software QPainter path and the OpenGL/allshader
  path) draw identically, so the look is the same however Mixxx renders.

**Tuning the size** (for future tweaks): the two size knobs live in
`mixxx-patch/beatgrid-ticks.patch`, as named constants in each renderer —
`kBeatTickFraction` (tick/bar height, a fraction of the waveform height; ~0.11)
and `kBarHalfWidth` (red bar half-width in pixels; 1.5 → ~3px wide). Lower
`kBeatTickFraction` for shorter ticks, lower `kBarHalfWidth` for thinner bars.

The play-position marker (the moving playhead) is unchanged.

## Install (on the Pi)

```
sudo ./update-pioneered.sh
```

## Field checks

1. Load a rekordbox-analysed track: the beat marks are short ticks hugging the
   top and bottom edges, and the middle band of the waveform is clear (no
   full-height beat lines).
2. Bar starts show a thin **red vertical bar** at the top and bottom — no red
   triangles/arrows anywhere.
3. Zoom the waveform in and out: the ticks and red bars stay a sensible small
   height at every zoom level and remain visible on a short/shallow waveform.
4. The playhead (current-position marker) looks the same as before.
